# Hackathon pitch deck

[rolecraft-pitch-deck.pdf](rolecraft-pitch-deck.pdf) is the 13-slide deck from the hackathon.

It presents an earlier version of Rolecraft, a focus-plan tool with an optional live mode that used a hosted AI service. That version is archived at the git tag `archive/hackathon-live-analysis` and is not in `main`, because it needs paid API access. In this repository:

- The live mode, the outreach email and the focus-plan flow shown in the deck do not exist.
- The offline engine and the principle that every claim traces back to your own words carry over. The interface has since been redesigned around five workflows.
- Figures quoted in the deck (34 role families, 136 skill terms, 816 test checks) describe the hackathon build, not the current code.
