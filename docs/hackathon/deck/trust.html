2:48 to 2:54. About 6 seconds. Do not linger here. SAY: "It is private by default, accessible, tested, and guarded." THE FACTS BEHIND EACH CARD: Private: files are read in the browser and nothing is stored. The offline engine sends nothing anywhere. In live mode a consent screen lists the exact text that would be sent, and the server refuses a request that lacks the consent flag. The server does not log request bodies. Accessible: an automated axe-core audit of every step at 1280 px and 390 px found no violations, and a scripted keyboard pass confirmed skip link, error-summary focus, focus moving to each page heading, arrow keys on the direction radios and the tabs. This does not replace testing with a screen reader and real users. Tests: 816 checks across five suites: 12 engine, 133 grounding and orchestration, 509 vocabulary and rewrite rules, 152 network guard and 10 API request checks. Guarded server: the URL fetch accepts public HTTPS hosts only, resolves the hostname and refuses any private, loopback, link-local, multicast or unique-local address, IPv4 or IPv6. Routes accept same-origin requests, cap the body and limit requests per client. Honest limits: no login, and a DNS answer could still change between the check and the fetch.
